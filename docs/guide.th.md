# คู่มือการใช้งาน

[English](guide.md) · **ภาษาไทย** · [กลับไปที่ README](../README.th.md)

## หน้าจอมีอะไรบ้าง

- หน้า **library** มีการ์ดต่อหนึ่งเกม บนปกบอกสถานะสด (`2/2 ONLINE`, `1 DISCONNECTED`, `NOT RUNNING`) เกมที่เปิดเตือนไว้แล้วหลุดจะขึ้นขอบแดง
- สวิตช์ **Alerts on / off** บนการ์ดเลือกว่าเกมไหนจะเตือน เปิดหลายการ์ด = เฝ้าหลายเกมพร้อมกัน ปุ่มกรองด้านบนเลือกดูทั้งหมด / เฉพาะที่เปิดเตือน / เฉพาะที่เปิดเกมอยู่
- คลิกการ์ดเพื่อเข้าหน้าของเกมนั้น ด้านบนมีปก สถานะ และสวิตช์เตือน ตามด้วยการ์ดต่อหนึ่ง client กด **Library** เพื่อกลับ
- แถบบนบอกสถานะรวม (ALL ONLINE / 1 DISCONNECTED / GAME NOT RUNNING / PAUSED), สถานะเน็ต, ปุ่ม Start/Pause และบอกว่าเช็คล่าสุดเมื่อไหร่ รอบถัดไปอีกกี่วินาที
- การ์ดต่อหนึ่ง client บอก ONLINE/หลุด, PID, ปลายทางที่ต่ออยู่, ต่อเนื่องมานานแค่ไหน หรือหลุดมานานเท่าไหร่
  ช่วงที่ socket หายแต่ยังไม่ครบ grace จะขึ้น `CONFIRMING 1/3` สีเหลือง
- ไอคอน **หมุด** บนการ์ด client จะตรึงหน้าต่างเกมนั้นให้อยู่บนสุดเสมอ เปิดโปรแกรมอื่นเต็มจอทำงานไปก็ยังเห็นเกม ระหว่างตรึงไอคอนเป็นสีฟ้า กดอีกครั้งเพื่อเลิกตรึง ย่อหน้าต่างเกมให้เล็กแล้ววางไว้มุมจอก่อน ใช้ได้กับโหมด windowed / borderless ไม่ได้กับ fullscreen แบบ exclusive ตรึงไว้จนกว่าหน้าต่างเกมจะปิด ถ้าเกมรันแบบ administrator ต้องรัน Gamepulse แบบ administrator ด้วย
- ไอคอน **ภาพซ้อนภาพ** ข้างกันเปิดจอเล็กแสดงเกมนั้นแบบสด ลอยอยู่บนทุกหน้าต่าง เหมือนย่อจอวิดีโอ ลากเพื่อย้าย ลากขอบเพื่อย่อ/ขยาย (สัดส่วนตามเกม) ดับเบิลคลิกเพื่อกลับไปที่เกม หรือคลิกขวาเปิดเมนู **อย่า minimize เกม** เพราะ Windows หยุดวาดหน้าต่างที่ถูกย่อ จอเล็กจะดับ ให้ปล่อยเกมไว้ข้างหลังโปรแกรมอื่นแทน (โดนบังแล้วยังวาดอยู่) ภาพนี้ Windows วาดเองด้วย GPU แทบไม่กิน CPU และ Gamepulse ไม่ได้อ่านหรือบันทึกภาพไว้เลย
- ช่อง Events ไล่ประวัติว่าหลุด/ส่งเตือนตอนไหนบ้าง (ผลเช็คแต่ละรอบขึ้นเฉพาะตอนเปลี่ยน ส่วนไฟล์ log บันทึกทุกรอบ)
- แถบล่างบอกช่องทางเตือนที่ตั้งไว้ และ heartbeat รอบถัดไป
- ปิดหน้าต่าง = ย่อลง tray ไม่ใช่ปิดโปรแกรม คลิกซ้ายที่ไอคอน tray เพื่อเปิดกลับ ออกจริงคลิกขวา > **Exit**
- เปิด exe ซ้ำตอนที่ตัวเดิมเปิดอยู่ จะเรียกหน้าต่างเดิมขึ้นมา (เปิดได้ทีละตัว)

ปุ่ม **Guide** ที่หน้าหลักอธิบายความหมายของสถานะแต่ละสี, เตือนตอนไหน, แต่ละค่าใน Settings,
วิธีตั้งมือถือ และการแก้ปัญหา มีปุ่ม **Run setup again** ถ้าอยากเข้าหน้าตั้งค่าครั้งแรกใหม่

## Settings

| หมวด | มีอะไร |
|---|---|
| Appearance | เลือก theme: Midnight (ค่าเริ่มต้น), Night Watch, Poring, Frost, Mocha, Daylight — เห็นผลทันที กด Cancel แล้วกลับเป็นค่าเดิม |
| Notifications | ntfy topic/server, Discord webhook, Telegram bot, `@here`, เสียงที่เครื่องนี้ |
| Test your setup | **Test alert**, **Run drill**, **Test heartbeat**, **Capture desktop** — ใช้ค่าที่อยู่บนหน้าจอ แม้ยังไม่กด Save |
| Detection | ช่วงเวลาตรวจ, grace checks |
| Wake-up alerts | เตือนซ้ำทุกกี่นาที, ซ้ำสูงสุดกี่ครั้ง, หนึ่งรอบยิงกี่ใบ, ห่างกันกี่วินาที |
| Heartbeat | ส่งทุกกี่ชั่วโมง, แนบภาพหน้าจอไป Discord |
| MVP tracker | เตือนก่อนเกิดกี่นาที, เตือนเหตุการณ์ไหนบ้าง, ส่งไป Discord และ/หรือ Windows notification, ปุ่ม **Test MVP alert** |
| App | เปิดพร้อม Windows, เริ่มเฝ้าทันทีเมื่อเปิดแอป |

- **Test alert** ยิงหนึ่งชุดเข้าทุกช่องทาง พิสูจน์แค่ว่า "ส่งถึง"
- **Run drill** ยิงชุดเดียวกับตอนหลุดจริง 5 รอบ ห่างกันตาม `Repeat every` ข้อความมีคำว่า `DRILL` กำกับ
  พิสูจน์ว่า "ปลุกติด" ซึ่งเป็นคนละเรื่องกัน drill เดินต่อแม้ปิด Settings และหยุดได้จากปุ่ม **Stop drill** ที่หน้าหลัก
- **Test heartbeat** ส่ง heartbeat ทันที ถ้าเปิดแนบภาพไว้จะได้เห็นว่าภาพไปถึง Discord จริง
- **Capture desktop** เซฟภาพ BMP ลงโฟลเดอร์ `screenshots/` เฉยๆ ไม่ส่งไปไหน

### ใช้ ntfy

ลงแอป **ntfy** จาก Play Store / App Store กด **+** แล้ว subscribe topic ชื่อเดียวกับที่ใส่ใน Gamepulse
(หน้าตั้งค่ามีปุ่ม **Generate** สุ่มชื่อที่เดายากให้ และปุ่ม **Copy**)

ชื่อ topic ห้ามบอกใคร เพราะ ntfy.sh เป็น server สาธารณะ ใครรู้ชื่อ topic ก็อ่านข้อความได้
(ข้อความมีแค่ PID กับเวลา ไม่มีข้อมูล account) ถ้าอยากปิดสนิทจริงๆ ต้อง self-host ntfy เอง แล้วใส่ใน `ntfy server`

## MVP tracker

หน้าเกม Ragnarok Origin Classic มีส่วน **MVP tracker** อยู่ใต้การ์ด client ปิดไว้จนกว่าจะกด **Turn on**

- MVP ทุกตัวเกิดใหม่ 1 ชั่วโมงหลังตาย และเกมประกาศให้ทั้งเซิร์ฟเวอร์เห็นที่แถบข้อความล่างจอของหน้าต่างเกม: ใครฆ่า MVP ตัวไหน, "จะปรากฏใน 5 นาที", "ปรากฏแล้ว" และ "HP 30%" ระหว่างเปิด tracker ไว้ Gamepulse จะดึงภาพหน้าต่างเกมทุก 1 วินาที อ่านแถบนั้นด้วย OCR ที่มากับ Windows แล้วนับเวลาแยกตาม MVP แต่ละตัว อ่านได้แม้เกมเข้าโหมดประหยัดพลังงาน (จอมืดลงหลังไม่ได้แตะเกมสักพัก)
- **เปิดหน้าต่าง Event › MVP ในเกมเป็นระยะ** เพื่อให้เวลาตรงเป๊ะ: ระหว่างที่หน้าต่างนี้เปิดอยู่ใน client ไหนก็ได้ Gamepulse จะอ่านเวลานับถอยหลังของทุกแถวที่เห็นบนจอแล้วใช้เวลาของเกมเลย (เลื่อนดูแถวที่เหลือได้) ช่วยแก้ตัวที่พลาดประกาศและเวลาที่ประเมินเอง แถวที่ขึ้นว่า "รีเฟรชแล้ว" จะถือว่าเกิดอยู่ ถ้า Gamepulse ไม่เห็นตอนเกิดจะขึ้น **Up · spawn time unknown** ส่วนถ้าประกาศเลือด 30% แล้ว 5 นาทียังไม่เห็นประกาศตาย จะถือว่าตายแล้วและประเมินเวลาเกิดไว้ก่อน จนกว่าหน้าต่าง MVP หรือประกาศจะบอกเวลาจริง
- รายการแสดง MVP ตามลำดับในเกม พร้อมแมปและสถานะ สี: **เขียว** = เกิดอยู่, **ส้ม** = เกิดอยู่และเกมประกาศว่าเลือดเหลือ 30%, **ฟ้า** = จะเกิดภายในเวลาเตือนที่ตั้งไว้, **แดง** = ตายแล้ว กำลังนับถอยหลัง (**Spawns 22:39 · in 34m**), **เทา** = ยังไม่เห็นตั้งแต่เปิด tracker เวลาถูกเก็บใน `bosses.json` ปิดเปิดแอปใหม่แล้วยังนับต่อ ถ้าปิด Gamepulse หรือปิด tracker ไปนาน เวลาเดิมอาจเพี้ยน กด **Clear timers** (กด 2 ครั้ง) เพื่อล้างทั้งหมดแล้วเริ่มนับใหม่จากประกาศถัดไป
- ปุ่ม **Route window** เปิดหน้าต่างเล็กที่ลอยอยู่เหนือเกม บอกว่าควรไปตีตัวไหนก่อน: ตัวที่เลือด 30% ขึ้นก่อน (บอกด้วยว่าประกาศ 30% มานานเท่าไหร่แล้ว ตัวที่เพิ่งประกาศอยู่บนสุด เพราะปกติตายภายในไม่กี่นาที) ตามด้วยตัวที่เกิดอยู่ แล้วตัวที่เหลือเรียงตามเวลาเกิด ลากไปวางตรงไหนก็ได้ คลิกขวาเพื่อเลือกแสดงเฉพาะตัวที่ติ๊กหรือทั้งหมด หรือปิดหน้าต่าง ซ่อน Gamepulse ลง tray แล้วยังอัปเดตต่อ
- รูป MVP ไม่ได้แถมมากับแอป (ภาพเป็นลิขสิทธิ์ของผู้จัดจำหน่าย) ถ้าอยากให้แสดง ใส่ไฟล์ PNG ตั้งชื่อตาม MVP ในโฟลเดอร์ `mvps` ข้าง `config.json` เช่น `mvps/golden-thief-bug.png` ถ้าไม่มีรูปจะแสดงตัวอักษรแรกแทน
- ติ๊ก MVP ที่อยากให้เตือน (**Tick all** / **Untick all**) ส่วน Settings > **MVP tracker** เลือกว่าจะเตือนอะไร: เตือนก่อนเกิดกี่นาที (ค่าเริ่มต้น 10, ใส่ 0 = ปิด), ตอนเกิด, ตอนตาย, ตอนเลือดเหลือ 30% ถ้าเพิ่งเริ่มนับจากประกาศ 5 นาทีของเกม จะเตือนทันที
- เตือน MVP ส่งไป **Discord webhook** และ/หรือ **Windows notification** อย่างละหนึ่งข้อความ ไม่ส่งไป ntfy หรือ Telegram และไม่เตือนซ้ำ เพราะไม่ใช่การปลุก
- ต้องเปิดหน้าต่างเกมไว้อย่างน้อยหนึ่งตัว โดนหน้าต่างอื่นบังได้ แต่ **ห้าม minimize** (Windows หยุดวาดหน้าต่างที่ถูกย่อ) ถ้ามีหลาย client จะอ่านตัวที่เปิดล่าสุด ถ้าเกมรันแบบ administrator ต้องรัน Gamepulse แบบ administrator ด้วย ไม่งั้นสถานะจะขึ้น **CAN'T READ**
- ดูแค่หน้าต่างของเกมเอง ไม่ส่งอะไรเข้าเกม และไม่บันทึกหรืออัปโหลดภาพ ปิด tracker แล้วหยุดจับภาพทันที ไม่กิน CPU

## ปกเกม

ปกเกมไม่ได้แถมมากับแอป (ภาพเป็นลิขสิทธิ์ของผู้จัดจำหน่าย) ทุกเกมใช้ปก placeholder โล่งๆ ถ้าอยากใส่เอง: คลิกขวาที่การ์ดเกม (หรือกดไอคอนรูปภาพที่โผล่บนปกตอนชี้) > **Choose cover image**
แล้วเลือกไฟล์ PNG, JPG หรือ WebP (แนวตั้ง 3:4 สวยสุด) แอปจะเก็บสำเนาไว้ในโฟลเดอร์ `covers` ข้าง exe กด **Remove cover** เพื่อกลับไปใช้ placeholder

## ค่าที่ตั้งไว้เก็บที่ไหน

ค่าทั้งหมดเก็บใน `config.json` ข้างไฟล์ exe เวลาของ MVP อยู่ใน `bosses.json` ส่วน log อยู่ที่ `gamepulse.log` ในโฟลเดอร์เดียวกัน
`config.json` มี webhook/token ห้ามส่งให้ใครหรือแนบตอนขอความช่วยเหลือ
(ถ้า build เองจาก repo นี้ แอปจะใช้ `config.json` ที่ root ของ repo แทน ไฟล์นี้ถูก gitignore ไว้แล้ว)

## ตั้งให้เปิดเองตอนเข้า Windows

Settings > App > ติ๊ก **Open Gamepulse when I sign in to Windows** แล้ว Save
(เขียนลง `HKCU\Software\Microsoft\Windows\CurrentVersion\Run` ไม่ต้องใช้สิทธิ์ admin และไม่ต้องใช้ Task Scheduler)
ติ๊ก **Start watching when the app opens** ไว้ด้วย ไม่งั้นแอปเปิดขึ้นมาแต่ยังไม่เฝ้า
ถ้าย้ายโฟลเดอร์ exe หรืออัปเดตเป็นเวอร์ชันใหม่ในโฟลเดอร์อื่น ให้ติ๊กออกแล้วติ๊กใหม่ เพื่อบันทึก path ใหม่
อัปเกรดจาก ROOC Monitor: ถ้าเคยเปิดให้เปิดพร้อม Windows ไว้ Gamepulse จะย้ายค่านั้นมาชี้ที่ตัวเองตอนเปิดครั้งแรก

สำคัญกว่าตัวแอป: ไปตั้ง Power Options ให้ **Sleep = Never** ด้วย
ไม่งั้นเครื่องหลับแล้วทั้งเกมทั้ง monitor ก็ตายตามกัน ซึ่งอาจเป็นต้นเหตุที่หลุดตอนนอนตั้งแต่แรก

## อัปเดตเวอร์ชัน

1. คลิกขวาไอคอนใน tray > **Exit** (กด X แค่ซ่อนหน้าต่าง ไฟล์จะยังถูกล็อก)
2. แตก zip เวอร์ชันใหม่ทับไฟล์ `.exe` เดิมในโฟลเดอร์เดียวกัน `config.json` ไม่ถูกแตะ ค่าที่ตั้งไว้ยังอยู่

## ถอนการติดตั้ง

ไม่มีตัว uninstall แอปเขียนไฟล์แค่ในโฟลเดอร์ตัวเอง, ค่าเปิดพร้อม Windows หนึ่งค่าใน registry และชื่อกับไอคอนของ Windows notification

1. ถ้าติ๊ก **Open Gamepulse when I sign in to Windows** ไว้ ให้ติ๊กออกแล้ว Save ก่อน ไม่งั้น Windows จะพยายามเปิดไฟล์ที่ไม่มีแล้วทุกครั้งที่เข้าเครื่อง
2. คลิกขวาไอคอนใน tray > **Exit**
3. ลบโฟลเดอร์ทิ้ง จะลบ exe, `config.json` (มี webhook และ token), `bosses.json`, `gamepulse.log` และโฟลเดอร์ `screenshots` ไปพร้อมกัน
4. ถ้าเคยใช้ Windows notification ลบ `HKCU\Software\Classes\AppUserModelId\Gamepulse` และโฟลเดอร์ `%LOCALAPPDATA%\Gamepulse` (ชื่อและไอคอนของ notification) ได้ด้วย

## คำสั่ง command line

`gamepulse-cli.exe` (อยู่ใน zip เดียวกัน) แยกจากตัว GUI ใช้ตรวจสถานะครั้งเดียวหรือทดสอบการจับภาพ ไม่เฝ้าและไม่ส่งเตือน:

```powershell
.\gamepulse-cli.exe --once      # JSON snapshot; exit 0 ออนไลน์ครบ, 1 มีตัวหลุด, 2 ไม่มีเกมที่รองรับเปิดอยู่, 3 อ่านไม่ครบ
.\gamepulse-cli.exe --capture   # จับภาพ desktop แล้วรายงาน metadata ไม่เขียนไฟล์
.\gamepulse-cli.exe --mvp-probe 60   # อ่านประกาศ MVP 60 วินาทีแล้วพิมพ์สิ่งที่อ่านได้ (ถ้าเกมรันแบบ administrator ต้องรันแบบ administrator ด้วย)
.\gamepulse-cli.exe --help
```

การ build จาก source, test และวิธีออก release อยู่ใน [DEVELOPMENT.md](../DEVELOPMENT.md) (ภาษาอังกฤษ)
